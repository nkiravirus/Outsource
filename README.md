# Outsource Nexus Pvt. Ltd.

Responsive company website for Outsource Nexus, showcasing business operations, finance and accounting, custom software, digital marketing, web and app development, hosting, and business documentation services.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and does not require a build step.

## Brand assets

The company logo is stored in `assets/outsource-nexus-logo.png`.
